# onemorestudio AI 口播视频 · 项目说明

## 定位
- 工作室：ONEMORE STUDIO（服装视频剪辑工作室，有审美）
- 客群：服装品牌、内容博主
- 痛点：博主时间被剪辑吃掉（选题、脚本、拍摄、选品、商务、运营）
- 主张：你负责拍，我负责剪，把时间还给你
- 平台：抖音 + 小红书，竖屏 9:16，35–40 秒，双平台通用

## 口播脚本

| 时间 | 画面 | 口播 |
|---|---|---|
| 0–4s | 数字人近景，纯色背景 | 一条视频，拍摄两小时，剪辑八小时。 |
| 4–12s | 侧身，手部动作 | 时间被剪掉的不是几个小时，是选题、脚本、选品、商务。 |
| 12–22s | 半身，工作室环境 | ONEMORE STUDIO，服装视频剪辑工作室。你们拍，我们剪。 |
| 22–32s | 版型、面料细节特写 | 版型、面料、走位、节奏，我们替你判断哪一帧值得留。 |
| 32–40s | 正面，收尾 | 把素材丢过来，成片交给你。把时间，还给你自己。 |

- 字幕：底部两行，无描边，字号中等，关键词加粗变色
- 音乐：克制氛围纯音乐，人声优先
- CTA：主页私信「剪辑」领报价单

## 制作流程
1. 脚本定稿（口吻、logo 待确认）
2. 素材：`ai数字人.JPG` → 剪映「数字人」生成形象
3. 配音：文本朗读 → 挑选音色 → 试听
4. 字幕：识别字幕 → 逐句校对断句 → 加动画
5. 包装：工作室素材做转场与细节层
6. 导出 4K60 + 9:16，存档并推送 GitHub

## 合规

- 不承诺涨粉、播放、收益

## 视觉与节奏规则（来自 3 条对标片）
1. 底色干净（白墙或深灰），不打灯效
2. 每 8–10 秒换气：章节卡 / 黑场 0.5s / B-roll
3. 文字承担信息，画面承担情绪
4. 高亮只用一色（暖橙 #FFB84D）
5. 字幕位置固定，不上下跳
6. B-roll 只做证据（版型、面料、走线），不做装饰混剪

## 时长结论
- 脚本 120 字，舒适语速 4.2–4.8 字/秒 → 实际约 26–29 秒
- 方案 A：不加字，压到 30s（推荐，完播率更高）
- 方案 B：补 30–40 字，做到 36–40s
