# 新项目交接：onemorestudio AI 口播视频

## 1. 项目与目标
- 项目名：`onemorestudio ai视频`
- 工作目录：`~/Desktop/小One剪辑文件/onemorestudio-ai视频/`（同时纳入 GitHub 仓库 `onemorestudio888/xiaone-video-workflow`）
- 工作室：ONEMORE STUDIO，服装领域视频剪辑工作室，主打有审美的成片
- 目标：做一条 AI 数字人口播短视频，用于抖音 + 小红书引流获客
- 规格：竖屏 9:16，35–40 秒，导出 4K 60 帧

## 2. 内容定位
- 客群：服装品牌、内容博主
- 痛点：博主的时间被剪辑吃掉——选题、写脚本、拍摄、选品、商务、账号运营都被挤压
- 主张：你负责拍，我负责剪，把时间还给你
- 差异点：有审美、懂版型和面料、知道前 3 秒怎么留人

## 3. 口播脚本（约 40 秒）

| 时间 | 画面 | 口播 |
|---|---|---|
| 0–4s | 数字人近景，纯色背景 | 一条视频，拍摄两小时，剪辑八小时。 |
| 4–12s | 侧身，手部动作 | 时间被剪掉的不是几个小时，是选题、脚本、选品、商务。 |
| 12–22s | 半身，工作室环境 | ONEMORE STUDIO，服装视频剪辑工作室。你们拍，我们剪。 |
| 22–32s | 版型、面料细节特写 | 版型、面料、走位、节奏，我们替你判断哪一帧值得留。 |
| 32–40s | 正面，收尾 | 把素材丢过来，成片交给你。把时间，还给你自己。 |

- 字幕：底部两行，无描边，字号中等，关键词加粗变色
- 音乐：克制氛围纯音乐，人声优先
- CTA：主页私信「剪辑」领报价单

## 4. 制作流程
1. 脚本定稿（口吻、片头 logo 待确认）
2. 数字人：`ai数字人.JPG` → 剪映「数字人」生成形象
3. 配音：剪映「文本朗读」生成，试听挑音色
4. 字幕：识别字幕 → 逐句校对断句 → 加动画
5. 包装：工作室素材做转场与细节层（版型、面料特写）
6. 导出 4K60 + 9:16，存档到项目目录并推送 GitHub
